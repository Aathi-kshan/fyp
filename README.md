# Financial Report Summarization System

A minimal UI system for generating automated summaries of financial reports using a fine-tuned TinyLlama model.

## Project Structure

```
project_root/
│
├── ui/
│   └── app.py              # Gradio UI application
│
├── model/
│   └── fine_tuned_model.pt # Fine-tuned TinyLlama model (1.02 GB)
│
├── utils/
│   ├── __init__.py         # Package initialization
│   ├── pdf_loader.py       # PDF text extraction
│   └── inference.py        # Model loading and inference
│
├── requirements.txt        # Python dependencies
└── README.md              # This file
```

## Features

- **PDF Upload**: Upload financial report PDFs through a simple web interface
- **Text Extraction**: Automatic extraction of text content from PDFs
- **AI Summarization**: Generate concise summaries using fine-tuned TinyLlama model
- **Preview Display**: View extracted text and generated summaries

## Installation

### Option 1: Local Environment

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
python ui/app.py
```

3. Open your browser to: `http://localhost:7860`

## Usage

1. **Upload PDF**: Click "Upload Financial Report (PDF)" and select your file
2. **Generate Summary**: Click the "Generate Summary" button
3. **View Results**: 
   - Extracted text preview appears in the left panel
   - Generated summary appears in the bottom panel

## Model Information

- **Base Model**: TinyLlama-1.1B-Chat-v1.0
- **Fine-tuning Method**: LoRA (Low-Rank Adaptation)
- **Training Dataset**: FNS 2022 (Financial Narrative Summarisation)
- **Model Size**: 1.02 GB
- **Quantization**: 4-bit for memory efficiency

## Requirements

- Python 3.8+
- CUDA-capable GPU (recommended) or CPU
- ~4GB RAM minimum
- ~8GB GPU VRAM (if using GPU)

## Notes

- First run will download the base TinyLlama model (~2.2GB) from HuggingFace
- Processing time depends on document size and hardware
- GPU acceleration significantly improves performance
- The UI is intentionally minimal and functional

## Troubleshooting

**Model not loading:**
- Ensure `fine_tuned_model.pt` exists in the `model/` directory
- Check that you have sufficient memory/VRAM

**PDF extraction fails:**
- Verify the PDF is not encrypted or password-protected
- Ensure the PDF contains extractable text (not scanned images)

**Out of memory errors:**
- Reduce batch size or use CPU instead of GPU
- Close other applications to free up memory
